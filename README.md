# Reg.ru IP Hunter

Утилита для поиска нужных IP-адресов в Reg.ru Cloud.

Бот создает временные облачные серверы Reg.ru, проверяет выданный IP и удаляет сервер, если IP не подходит. Когда найден подходящий IP, бот останавливает поиск и оставляет найденный сервер.

## Что нужно для запуска

- Telegram bot token
- ваш Telegram user/chat ID
- API token Reg.ru Cloud
- Docker и Docker Compose

Важно: **API token Reg.ru Cloud не указывается в `.env`**. В `.env` добавляются только данные Telegram-бота. Токен Reg.ru вводится позже в самом Telegram-боте при добавлении аккаунта.

## Где взять API token Reg.ru Cloud

1. Зайдите в личный кабинет Reg.ru.
2. Откройте раздел облачных серверов Reg.ru Cloud.
3. Перейдите в раздел **API** или **Настройки -> API**.
4. Скопируйте API token.

Этот токен бот использует для запросов к Reg.ru Cloud API, например для создания и удаления reglet-серверов.

## Куда вставлять API token Reg.ru Cloud

После запуска бота откройте его в Telegram:

1. Отправьте `/start`.
2. Нажмите **Аккаунты**.
3. Нажмите **Новый аккаунт**.
4. Введите название аккаунта, например `workspace`.
5. На шаге **API токен** вставьте API token Reg.ru Cloud.
6. Выберите регионы.
7. Введите цель для поиска IP.

Токен будет сохранен в локальном файле данных бота: `data/storage.json`.

## Настройка `.env`

Скопируйте пример:

```bash
cp .env.example .env
```

Заполните только Telegram-переменные:

```env
TELEGRAM_BOT_TOKEN=1234567890:AA...
TELEGRAM_USER_ID=123456789
```

Как получить `TELEGRAM_BOT_TOKEN`:

1. Откройте `@BotFather` в Telegram.
2. Создайте бота через `/newbot`.
3. Скопируйте выданный токен.

Как узнать `TELEGRAM_USER_ID`:

1. Откройте `@userinfobot` в Telegram.
2. Он пришлет ваш Telegram ID.

## Запуск

```bash
docker compose up --build -d
```

Логи:

```bash
docker compose logs -f
```

После запуска откройте своего Telegram-бота и отправьте `/start`.

## Данные аккаунта

Для каждого аккаунта в Telegram-боте указываются:

- название аккаунта
- API token Reg.ru Cloud
- целевой IP, префикс, wildcard или CIDR-подсеть
- регионы для перебора

Можно добавить несколько аккаунтов с разными токенами Reg.ru Cloud.

## Поддерживаемые форматы цели

- `1.2.3.4` - точный IP
- `1.2` - префикс
- `1.*.*.4` - wildcard
- `1.2.3.0/24` - CIDR-подсеть
- `1.2, 5.6` - несколько целей через запятую

Пример:

```text
31.31.197.0/24, 37.140.192.0/24, 37.140.193.0/24
```

## Важная безопасность

Не публикуйте `.env`, `data/storage.json`, Telegram bot token и API token Reg.ru Cloud.

Если токен случайно попал в чат, скриншот, репозиторий или логи, лучше перевыпустить его в панели Reg.ru или у `@BotFather`.
